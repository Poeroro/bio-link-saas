# LinkPilot Bio Link SaaS

Website bio link seperti Linktree yang dibuat dengan Next.js, Tailwind CSS, dan localStorage. App ini berisi landing page, auth dummy, dashboard user, editor profil, link manager, public bio page, QR code, share/copy link, analytics dummy, dark mode, dan preview realtime.

## Fitur

- Landing page modern dan responsive
- Login/register dummy
- Dashboard user
- Edit profile
- Tambah, edit, hapus link
- Aktif/nonaktif link
- Drag and drop urutan link
- Public bio page di `/u/username`
- 9 pilihan template tema
- Analytics dummy
- QR code
- Copy link dan share link
- Dark mode
- Data tersimpan di localStorage
- Toast notification, loading state, empty state
- Preview bio page realtime
